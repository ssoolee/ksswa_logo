한국사회복지행정연구회(한사연 / KSSWA, https://ksswa.or.kr)의 공식 캐릭터 개발 산출물 저장소.

**🌱 캐릭터 소개 페이지 → https://ksswa-logo.web.app**
조형 원리·프로필·사용 규정·원본 파일 내려받기를 한 페이지에 담은 **시안**이다.
소스는 `web/`, 배포는 Firebase Hosting(Spark). 배포 명령: `firebase deploy --only hosting`

## 확정 캐릭터 — 품싹 (Poomsak)

| 항목 | 내용 |
|---|---|
| 이름 | **품싹** / **Poomsak** |
| 어원 | **품**(가슴으로 감싸 안은 자리 = CI 요람 곡선) + **싹**(새싹 = 성장) |
| 한 줄 정의 | 아직 자라는 중인데, 이미 자기 떡잎으로 남을 덮어주고 있는 새싹 |
| 핵심 메시지 | "당신이 매일 덮어준 만큼, 오늘은 당신이 덮일 차례입니다." |
| 성격 | 기존 CI를 **대체하지 않는 보조 자산**. CI와 병기·공존한다 |

**CI 계승 검증의 3대 불변 조건** — 어떤 파생물에서도 변경 금지 (변경 시 재심의 사항)

1. **떡잎 정확히 2장 · 좌우 비대칭** (왼쪽=남을 덮는 잎, 오른쪽=자기를 감싸는 잎)
2. **두 팔이 아래에서 맞물려 품(빈 공간)을 만드는 구조** — 품은 어떤 색으로도 채우지 않는다
3. **맞물림 지점 `#54B947`** — CI 겹침색 그대로. 이 색이 CI 계승의 유일한 증거다

## SVG 검증 방법

캐릭터 SVG는 **반드시 렌더링해서 눈으로 확인**한 뒤 완성 처리한다.

```bash
# 기본 (512px, 흰 배경)
bash tools/render-svg.sh assets/character/poomsak-main.svg out.png 512

# 다크 배경 판독성 검증 — 품(빈 공간)으로 배경이 비치는지 확인
bash tools/render-svg.sh assets/character/poomsak-main.svg out-dark.png 512 "#111827"

# 축소 실루엣 검증 (이모티콘·파비콘 요건)
bash tools/render-svg.sh assets/character/poomsak-48.svg out-48.png 48
bash tools/render-svg.sh assets/character/poomsak-16.svg out-16.png 16
```

Chrome 헤드리스를 사용하므로 별도 라이브러리 설치가 필요 없다.

**검증 완료 항목** (`04` §6): 라이트/다크 배경 판독성, 48px·16px 축소 식별, 단색 실루엣 테스트 3종(떡잎 비대칭 판독 / 품이 닫힌 구멍으로 판독 / 물방울 역상 윤곽).
