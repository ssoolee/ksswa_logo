# Round 2 — 캐릭터 5안 시안 (공식 자산 아님)

이 폴더의 이미지는 **OpenAI `gpt-6-astra` 모델로 생성한 비교 검토용 시안**이다.
**공식 자산이 아니며, 공문·발간물·굿즈 등 대외 제작물에 그대로 사용하지 않는다.**

상세 분석은 [`docs/07-캐릭터-5안-비교.md`](../../../docs/07-캐릭터-5안-비교.md) 참조.

## 파일

안별로 **원안(색 중립)** 과 **한사연 채색안** 2장이 한 쌍이다.

| # | 안 | 원안 | 한사연 채색안 |
|---|---|---|---|
| 1 | 덤덤이 | `01-덤덤이-base.png` | `01-덤덤이-ks.png` |
| 2 | 조약이 | `02-조약이-base.png` | `02-조약이-ks.png` |
| 3 | 두리·아름 | `03-두리·아름-base.png` | `03-두리·아름-ks.png` |
| 4 | 복주임 | `04-복주임-base.png` | `04-복주임-ks.png` |
| 5 | 살피 | `05-살피-base.png` | `05-살피-ks.png` |

전 10장 1024×1024 PNG, **흰 배경 불투명**.

## 왜 공식 자산이 아닌가

1. **`docs/05-활용-가이드라인.md` §4-2 #15** — AI 생성 이미지를 캐릭터의 공식 재현물로 쓰는 것은 금지 항목이다. 조형 규칙이 유지된다는 보장이 없다.
2. **래스터다.** 공식 자산의 마스터는 벡터(SVG)이며, 래스터는 축소 시 사이즈별 외곽선 규칙을 만족시키지 못한다.
3. **네이밍 5종은 제안값이다.** 상표 선행조사를 거치지 않았다(`docs/01` §10 선결조건 1과 동일 제약).
4. 기존 공식 캐릭터 **「품싹」의 3대 불변 조건을 적용하지 않은 별도 라운드**다. 품싹 자산(`../poomsak-*.svg`)과 배포 사이트는 이 라운드의 영향을 받지 않는다.

## 공식화하려면

5안 중 1안을 조직이 선택한 뒤, **그 조형을 SVG로 다시 작도**하고 디자인 스펙 문서를 그 기준으로 개정하는 절차를 거친다. 래스터를 그대로 승격하지 않는다.

## 재현 방법

```bash
# OPENAI_API_KEY 환경변수 필요
node tools/round2-generate.mjs base all   # 1단계: 색 중립 원안 5종
node tools/round2-generate.mjs ks   all   # 2단계: 원안을 입력으로 한사연 팔레트 재채색
```

안 하나만 다시 만들려면 `all` 자리에 key를 넣는다 — `deomdeom` / `joyak` / `duri` / `bokjuim` / `salpi`.

## 알려진 제약

- `gpt-6-astra`는 **투명 배경을 지원하지 않는다**. `background: "transparent"`를 보내면 `Transparent background is not supported for this model` (HTTP 400)을 반환한다 (2026-10-30, 10-31 확인). `gpt-image-2.5-sunburst`도 동일하다. 따라서 전 10장이 흰 배경이며, 다크 배경에 쓰려면 별도 배경 제거가 필요하다.
- 재채색 단계에서 모델이 지시 일부를 누락하는 경우가 있다. 실제 누락 사항은 `docs/07` §4 검수표에 기록해 두었다.
