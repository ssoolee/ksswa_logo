# AI 업그레이드 시안 — 공식 자산 아님

이 폴더의 이미지는 **OpenAI `gpt-6-astra` 모델로 생성한 참고 시안**이다.
**공식 자산이 아니며, 공문·발간물·굿즈 등 대외 제작물에 그대로 사용하지 않는다.**

| 파일 | 내용 |
|---|---|
| `poomsak-svg-base-1024.png` | 공식 SVG 원본(`../poomsak-main.svg`)을 1024px로 렌더링한 입력 이미지 |
| `poomsak-astra-v1-1024.png` | 위 이미지를 입력으로 `gpt-6-astra`가 다시 그린 결과 (2026-10-30, 1024×1024, 흰 배경) |

## 왜 공식 자산이 아닌가

1. **`docs/05-활용-가이드라인.md` §4-2 #15** — "AI 생성 이미지로 품싹을 재현해 공식 사용"은 금지 항목이다. 조형 규칙이 깨지고, 공식물은 원본 SVG 기반이어야 한다.
2. **래스터다.** 마스터는 벡터(SVG)이며, 래스터는 축소 시 외곽선 규칙(사이즈별 전용 파일)을 만족시키지 못한다.
3. **스펙 수치와 일치하지 않는다.** `docs/04-디자인-스펙.md`의 좌표·두께·비율은 SVG 실측값이며, 이 이미지는 그 수치를 따르지 않는다.

## 불변 조건 충족 여부 (육안 검수)

| 조건 | 판정 |
|---|---|
| 떡잎 정확히 2장 · 좌우 비대칭 | **충족.** 다만 왼쪽 잎이 초승달 형태로 말려 잎보다 곡선 장식에 가깝게 읽힌다 |
| 두 팔이 맞물려 만든 품(빈 공간) | **충족.** 닫힌 구멍으로 명확히 판독된다 |
| 맞물림 색 `#54B947` | **충족.** 하단 교차 지점에 구분되는 녹색이 들어갔다 |
| 네이비 외곽선 · 활짝 웃지 않는 입 · 다리 없음 | **충족** |
| 잎맥 · 수첩 끈 | **누락.** 기본형 필수 요소는 아니다 |

## 이 시안을 공식화하려면

래스터를 그대로 쓰는 것이 아니라, **개선된 조형을 SVG로 다시 그려** `docs/04-디자인-스펙.md`를 개정하는 절차를 거친다.
떡잎 2장 비대칭 · 품 구조 · 맞물림 색은 변경 시 재심의 사항이므로(`05` §4-2, `06` §7-2 ⑥), 조형 변경 폭에 따라 승인 절차가 달라진다.

## 재현 방법

```bash
# OPENAI_API_KEY 환경변수 필요. tools/astra-upgrade.mjs 참조
node tools/astra-upgrade.mjs <입력PNG> <출력PNG> gpt-6-astra
```

투명 배경(`background: "transparent"`)은 `gpt-6-astra`와 `gpt-image-2.5-sunburst` 모두
`Transparent background is not supported for this model` 오류를 반환한다(2026-10-30 확인).
