## 2. 추진 배경 및 필요성

### 2-1. 조직 정체성을 설명할 자산이 부족하다

한사연은 1987년 사회복지전문요원(현 사회복지전담공무원) 최초 임용에서 출발한 **대한민국 사회복지전담공무원의 전국 조직**이며, 재적 대의원 662명(2021.3 대의원총회 기준), 17개 시·도 지회를 운영한다. 민간 사회복지사 단체가 아니라 **공공 복지행정 현장의 공무원 조직**이라는 점이 핵심 차별점이다.

그러나 이 차별점은 **현행 CI만으로는 설명되지 않는다.** CI는 조직의 공식 표지이고, 조직이 "어떤 사람들의 모임인지"를 이야기하는 기능은 수행하지 않는다.

### 2-2. 직군의 정서를 담을 그릇이 필요하다

본 프로젝트의 직군 심화 조사(`02` Part 1-4)는 사회복지전담공무원이 **감정노동과 업무과중**에 노출된 직군임을 확인했다. 따라서 캐릭터는 단순 홍보물이 아니라 **"돌보는 사람을 돌본다"** 는 정서를 담은 **회원 자긍심 자산**이어야 한다. 이는 브리프 §3이 1차 타깃 조건으로 명시한 사항이다.

### 2-3. 사회복지 직능 분야에 선례가 확인되지 않는다

벤치마킹 조사 결과, **한국사회복지협의회·한국사회복지사협회 양 전국 단체의 공식 캐릭터를 공개 웹 범위에서 확인하지 못했다**(`02` §2-2). 보건복지부 본부·질병관리청도 대표 마스코트가 확인되지 않았다.

> ⚠ 이는 "없다"가 아니라 **"확인하지 못했다"** 로 읽어야 한다. 다만 이 패턴은 한사연 캐릭터가 **사회복지 직능 분야의 선도 사례**가 될 여지를 뜻하며, 설립목적 1축("**최초** 공공복지행정 전문 인력")·3축("**개척자**")과 서사적으로 맞물린다. **공표 직전 양 협회 캐릭터 유무를 재확인하고 "최초"라는 표현은 신중하게 사용한다.**

### 2-4. 외부 노출 경로가 이미 확보되어 있다

2026 대한민국 지자체·공공 캐릭터 페스티벌 본선 74종 중 **공공기관 부문이 42종(57%)** 으로 지자체(22종)보다 많다(`02` §2-0). 공공 캐릭터는 더 이상 지자체 관광홍보 전용 도구가 아니며, **협회·공공기관 캐릭터도 제도적 수상·노출 경로를 갖는다.**

### 2-5. 설립목적 3축과의 정합성

| 설립목적 (공식 원문) | 품싹의 대응 |
|---|---|
| ① 최초 공공복지행정 전문 인력으로서 복지 발전의 역사적 사명 완수 | **서른아홉 번째 봄을 맞은 새싹** — 1987년을 발아 연도로 설정. 매년 "○○번째 봄"으로 갱신 |
| ② 복지 정보 교류를 통한 지식 공유화로 전문가 자질 함양 | **허리춤 수첩** — "적어두면 다음 사람이 덜 고생하니까요." 기록과 인계가 캐릭터의 고정 소품이다 |
| ③ 사회복지 전달체계 구축을 위한 개척자로서 복지국가 실현 | **땅을 보는 습관** — "아무것도 안 자란 땅을 알아보는" 특기. 아직 닿지 않은 곳을 본다 |

> 3축이 고르게 분산되어 **어느 한 축의 사업에만 쓰이는 편중이 없다**는 점이 A안 채택의 주요 근거였다(`03` §3-1).

### 3-1. CI 분석에서 확인된 중요 사실

공식 심볼은 **두 사람이 서로를 감싸 안은 형태**다. 좌측 오렌지 인물과 우측 그린 인물의 두 몸이 아래에서 맞물려 **품·요람 모양의 곡선**을 이루고, 겹치는 지점에 딥그린(`#54B947`)이 나타난다.

> **공식 CI 설명문은 그린을 "작은 새싹이 나무가 되는 무한한 성장"으로 서술하지만, 실제 조형은 새싹이 아니라 포옹하는 두 인물이다.** 따라서 캐릭터는 **성장 + 감싸 안음 두 의미를 모두 계승**해야 하며, 하나만 취하면 CI 연속성이 깨진다. 이것이 본 프로젝트의 최상위 제약이었다.

## 4. 개발 결과 — 캐릭터 「품싹」

### 4-1. 이름

| 항목 | 내용 |
|---|---|
| 표기 | **품싹** / **Poomsak** |
| 어원 | **품**(가슴으로 감싸 안은 자리 = CI 요람 곡선) + **싹**(새싹 = 성장) |
| 선정 사유 | CI의 **두 의미를 2음절에 모두** 담았고, 사전에 없는 **순수 조어**로 상표 식별력이 가장 높으며, 웹 검색상 동일 표기 선점 사례가 확인되지 않았다 |
| 조직 설명 문장 | **"품싹 — 품을 가진 새싹입니다. 저희 CI의 두 의미를 그대로 받았습니다."** 이 한 문장으로 정당성 설명이 끝난다 |

후보 12종 중 **보듬싹**(복지 분야 BI 상표권 등록 선례), **한싹이**(코스닥 상장사 사명과 음절 일치), **돋움이**(서체명 일반화), **복싹이**(인터넷 속어 연상), **케이싹**(K- 접두 식별력 미약) 등은 명확한 결격 사유로 탈락했다(`03` §2).

### 4-2. 조형 — CI 계승의 증거

```
       ○            ← 머리
     ╭───╮
     │   │          ← 몸통 (허리춤에 수첩)
     ╰─┬─╯
    ╱     ╲         ← 두 팔
   │  ( )  │        ← 품 : 빈 공간 (배경이 비쳐 보인다)
    ╲ ▓▓▓ ╱         ← 맞물림 지점 #54B947  ★ CI 겹침색
      ▒▒▒           ← 흙더미
```

| 요소 | 의미 |
|---|---|
| **떡잎 2장** | 새싹(성장) + CI의 "두 인물" 대응 구조 |
| **왼쪽 떡잎(길다)** | **남을 덮는 잎** |
| **오른쪽 떡잎(짧고 접혀 있다)** | **자기를 감싸는 잎** — 「돌보는 사람을 돌본다」의 조형적 구현 |
| **두 팔이 아래에서 맞물려 만든 품** | CI 요람 곡선(감싸 안음)의 계승 |
| **맞물림 지점 `#54B947`** | **CI 겹침색 그대로.** CI 계승 검증의 유일한 통과 조건 |
| **허리춤 수첩**(오렌지·옐로) | **CI 오렌지 인물의 치환 계승.** 기록과 인계 |
| **흙더미** | 다리가 없다. 현장에 묻혀 있다 |
| **네이비 외곽선** | 전문성·신뢰(CI 로고타입 색) |

> **핵심**: 떡잎을 **잎이자 팔로 이중 독해**한 것이 이 캐릭터의 설계 요점이다. 떡잎이 있으면 새싹이고, 그 아래에서 두 팔이 맞물리면 요람 곡선이다. 따라서 **단독 1개체로 노출되는 프로필 아이콘·파비콘·뱃지에서도 두 의미가 동시에 유지된다.**

### 4-4. 보이스 & 톤 요지

해요체 고정, 짧게 끊는다. 도입구는 **"오늘은요,"** 로 고정. **성과가 아니라 지속을 칭찬한다**("버텼네요", "오늘도 앉아 계셨네요"). 지시하지 않고 옆에 선다. 민원인·국민을 소재로 농담하지 않는다. **공식 문서에서는 1문장만 등장한다.**

> "최고예요!", "파이팅!" 류의 과잉 긍정은 감정노동 직군에게 공허하게 읽힌다는 조사 판단에 따라 **금지**했다(`02` Part 1-4, `03` §4).

## 5. 타당성 검토 — 실패하지 않기 위해 확인한 것

> 벤치마킹의 목적은 성공 사례 모방이 아니라 **실패 회피**였다. `02` §3-2는 공공 캐릭터 실패 원인을 5유형으로 정리했다.

| 유형 | 메커니즘 | 실증 사례 | **품싹의 대응** |
|---|---|---|---|
| **A. 지배구조 리스크** | 특정 리더의 치적으로 인식 → 교체 시 폐기 | 강남구 미미위(약 20억 투입 후 철거), 고양고양이(약 4년 사용 중단), 김해 토더기 | 한사연은 선출직 단체장 치적 수단이 아니므로 **구조적 이점**. 추가로 **회칙에 자산 귀속·폐지 의결 요건을 명문화**(§8-2) |
| **B. 전략 없는 반복 발주** | 필요할 때마다 개별 용역 → 캐릭터 난립 | 전주시 캐릭터 11개, 총 4.5억 원 | **지회 전용 캐릭터 전면 금지.** 지회는 「명판 병기」만 허용(`05` §7) |
| **C. 권리 미확보** | 저작권 양도·상표 등록 누락 | 강릉 홍길동(상표등록 취소), 송파구 CI 유사성 | **1단계를 권리 확보로 설계.** KIPRIS 선행조사 → 상표 출원을 다른 모든 전개보다 앞에 둔다 |
| **D. 공개·배포 인프라 부재** | 소개·다운로드 페이지가 없어 내부조차 못 씀 | 국가아동권리보장원 '아리', 근로복지공단 '희망' | **홈페이지 전용 페이지 개설 + 원본 파일 전면 공개 + 요소별 가치 매핑표 게시**를 1단계 필수 과제로 편성 |
| **E. 모티프-조직 무관성** | "왜 이 캐릭터인가"에 답하지 못함 | 전주 '싱이' 등 다수 | **CI 조형 원리 자체를 모티프로 삼았다.** "저희 CI의 두 의미를 그대로 받았습니다"로 설명이 종결된다 |

### 5-1. 직능단체 캐릭터는 지자체 캐릭터와 지표가 다르다

| 구분 | 지자체 캐릭터 | **한사연 캐릭터** |
|---|---|---|
| 1차 수요자 | 외부 일반 국민·관광객 | **내부 회원** |
| 성공 지표 | 굿즈 매출, 팔로워, 관광 유입 | **회원의 자발적 사용률** |
| 치명적 실패 조건 | 외부에서 모른다 | **회원이 창피해한다** |
| 톤 허용 범위 | B급·병맛 허용 | **공무원 조직의 품위 하한선이 존재** |
| 배포 정책 | 전략적 선택 | **회원 전면 개방이 필수.** 쓰지 못하면 자산이 아니다 |

> 따라서 본 계획의 KPI는 매출·팔로워가 아니라 **지회 자발적 사용률(17개소 중 10개소 이상)** 과 **회원 1인 1굿즈 보급률(80% 이상)** 이다(`06` §8).

### 5-2. 최우선 벤치마크 — 공무원연금공단 '믿음이'

2024 대한민국 캐릭터 페스티벌 **공공분야 대상 + 국민투표 인기상 2관왕**. 성공 요인 3가지를 본 계획에 그대로 반영했다(`02` §2-2 #15, §3-3).

| 믿음이의 방식 | 품싹에 반영한 내용 |
|---|---|
| **요소별 가치 매핑을 문서화** | §4-2 표 + 전용 페이지 게시 의무화 → 홍보 설명자료가 자동 생산된다 |
| **AI 원본 파일 공개** | `05` §9-3, `06` 1단계 과제 7 |
| 디자인은 대국민 공모, **이름은 내부 공모**로 분리 | 본 건은 내부 개발로 진행되었으므로 공모 절차는 없다. 대신 **총회 의결**로 조직 구성원의 채택 동의를 확보한다(§8) |

## 7. 소요 예산

> **본 계획서의 모든 금액은 추정값이다.** 공개 웹 자료에서 확인된 범위만 근거로 제시했고, 확인하지 못한 항목은 **「확인 불가」** 로 표기했다. **예산 상정 전 업체 견적 3건 이상 및 나라장터 유사 공고 낙찰가 확인을 권고한다.** 세부 내역은 `06` §6.

### 7-1. 이미 절감된 비용

| 항목 | 내용 |
|---|---|
| 캐릭터 디자인 개발 용역 | **0원 — 본 프로젝트 내부 산출로 대체** |
| 참고 | 업계 정리 자료는 공공기관·지자체 캐릭터 개발 단독 사업이 통상 **2,000만~5,000만 원** 규모로 발주되고 기획~납품에 **4~6개월**이 소요된다고 기술한다(추정 자료) |

### 7-2. 단계별 소요

| 단계 | 항목 | 추정액 |
|---|---|---|
| **1단계** (필수) | KIPRIS 선행조사 + 상표 출원(변리사 대리) | **확인 불가** (관납료 자료 불일치, 대리인 수수료 미확인) |
| | 상표 설정등록료 3개 류 | 약 60만 원 내외 **추정** (1류당 201,000원 자료 기준) |
| | Pantone·CMYK 색상 교정 / AI·EPS 변환 / 전용 페이지 제작 | **확인 불가** |
| | 가이드라인 PDF 편집·게시 | **0원** (산출물 활용) |
| **2~3단계** | 이모티콘 제작·배포 | **확인 불가** (공식 제안 요건 재확인 후 산정) |
| | 키링·뱃지 1,000 / 메모지 700 / 스티커 1,000세트 | **확인 불가** |
| **3~4단계** | 3D 모델링 | 200만~800만 원 **추정 구간** |
| | 모션 포함 | 500만~1,500만 원 **추정 구간** |
| | 탈인형 1~2기 | **확인 불가** (국내 단가 미확인. 해외 공방 USD 5,000~15,000+ 참고) |

### 7-3. 재원 조달 권고

1. **단계별 분할 상정** — 1단계(권리·인프라)만 먼저 의결하고, 성과 확인 후 2단계를 상정한다. 전주시형 반복 발주 구조를 피한다.
2. **굿즈 수익의 재투자 + 사회복지 기금 환원 병행.**
3. 외부 공모·지원사업 활용 검토(요강·자격 **확인 필요**).

> **"왜 협회 예산으로 캐릭터를 만드나"에 대한 답**: 용인시는 조아용 굿즈 매장을 **지역자활센터 자활사업 참여자가 직접 운영**하게 하고 수익을 자립지원 기금으로 환원했다(`02` §2-1 ⑥). 한사연도 **굿즈 수익을 사회복지 기금·회원 복지사업으로 환원**하고 연 1회 공개한다. 캐릭터가 복지 재원을 만드는 구조가 가장 강한 방어 논리다.
