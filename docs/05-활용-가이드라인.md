## 2. 배치 규칙

### 2-1. 최소 크기 (판독성 하한선)

| 매체 | 최소 크기 | 사용 파일 |
|---|---|---|
| 화면(웹·앱·PPT) | **가로 16px** | `poomsak-16.svg` |
| 화면 일반 사용 | 가로 48px 이상 권장 | `poomsak-48.svg` |
| 인쇄(오프셋·디지털) | **가로 15mm** | `poomsak-48.svg` 조형 |
| 인쇄 일반 사용 | 가로 25mm 이상 권장 | `poomsak-main.svg` |
| 자수(모자·점퍼) | **가로 30mm** 이상 | §8-3 단색 치환본 |
| 각인(금속·아크릴) | **가로 20mm** 이상 | §8-3 단색 치환본 |

> 16px 미만, 인쇄 15mm 미만에서는 **캐릭터를 쓰지 않고 CI 심볼만 쓴다.** 안 보이는 캐릭터를 넣는 것이 자산 가치를 가장 빠르게 떨어뜨린다.

### 2-2. 여백(Clear Space)

머리 지름(원본 좌표 기준 42)의 **절반 = 21** 이상을 사방에 비운다. 실제 사용 크기로 환산하면 **표시 높이의 약 1/6**이다.

```
┌─────────────────────────┐
│        ↑ 여백            │   표시 높이 120px → 여백 20px 이상
│   ←  ┌─────┐  →         │   표시 높이 240px → 여백 40px 이상
│  여백 │ 품싹 │ 여백       │
│      └─────┘            │
│        ↓ 여백            │
└─────────────────────────┘
```

여백 안에 들어와도 되는 것: **없다.** 로고·텍스트·사진·테두리·다른 캐릭터 모두 금지.

### 2-3. CI와 함께 쓸 때 (가장 자주 틀리는 부분)

품싹은 **CI를 대체하지 않는 보조 자산**이다(브리프 §3). 따라서 한 지면에 둘이 함께 있으면 **CI가 공식 발신 주체, 품싹은 안내자**다.

| 항목 | 규칙 |
|---|---|
| 위치 | CI는 **상단 또는 좌측**(공식 위치), 품싹은 **하단 또는 우측** |
| 크기 | 품싹 높이 ≤ **CI 심볼 높이 × 1.0.** 품싹이 CI보다 크면 안 된다 |
| 간격 | 두 자산 사이 **CI 심볼 높이의 1배 이상** |
| 금지 | CI와 품싹을 겹치기 · 품싹이 CI를 안거나 들고 있는 구도 · 품싹을 CI 안에 넣기 |
| 서명란 | 공문 발신 명의·직인 영역에는 **품싹을 넣지 않는다**(CI·기관명 전용 영역) |

> **판단 기준 한 줄**: "이 지면에서 말하는 주체는 한사연인가, 품싹인가?" 공식 발신(공문·협약·성명·법정 고지)은 항상 한사연이다. 품싹은 그 지면의 **도입부 한 칸**에만 들어간다.

### 2-4. 배경

| 배경 | 사용 파일 | 비고 |
|---|---|---|
| 흰색·밝은 단색 | 흰색 보조 외곽선 **제거판 사용 가능**(파일 경량화, 시각 차이 없음) | 04 §5-4 |
| 어두운 단색 | **흰색 보조 외곽선 포함판 필수** | 04 §5-4 |
| `--ks-navy` `#004B88` 배경 | 포함판 필수 | 네이비 외곽선이 배경에 묻힌다 |
| 그린 계열 배경 | **사용 금지.** 캐릭터 색과 충돌해 형태가 사라진다 | |
| 사진 배경 | **흰색 또는 네이비 단색 판을 깔고 그 위에 올린다.** 사진 위 직접 배치 금지 | |
| 패턴·그라데이션 배경 | 금지 | |

### 2-5. 품(빈 공간) 운용

두 팔 사이의 빈 공간은 **배경이 그대로 비쳐야** 한다(04 §3).

- ○ 비워 둔다 — 기본형 전 매체
- ○ 상황 일러스트에서 **다른 아이콘·짧은 문구·작은 캐릭터**를 넣는다
- ✕ 색으로 채운다 / 흰색으로 막는다 / 로고를 넣는다 / 사진을 넣는다
- ✕ 기본형 파일(4종)을 수정해 내용물을 넣는다 — **별도 파일로 제작한다**

## 3. 컬러 규칙

사용 가능한 색은 **브리프 §2 공식 토큰뿐**이다. 아래 표 밖의 색은 쓸 수 없다.

| 토큰 | HEX | 품싹에서의 용도 |
|---|---|---|
| `--ks-green-light` | `#BFD72F` | 머리, 몸통 상단 |
| `--ks-green` | `#AED136` | 떡잎 2장 |
| `--ks-green-deep` | `#95C93D` | 몸통 하단, 두 팔 |
| `--ks-green-overlap` | `#54B947` | **팔 맞물림 지점 — 변경·생략 절대 금지** |
| `--ks-orange` | `#F8991C` | 수첩 표지, 볼(18%) |
| `--ks-yellow` | `#FFDA00` | 수첩 속지 |
| `--ks-navy` | `#004B88` | 눈·입·외곽선 |
| `--ks-gray` | `#939598` | 흙더미(30·35%) |

### 금지 사례

| 금지 | 사유 |
|---|---|
| 계절·행사용 **컬러 변주**(핑크 봄 품싹, 빨간 성탄 품싹 등) | 공식 토큰 외 색 사용. 1회 변주가 허용되면 색 체계가 1년 안에 무너진다 |
| 검정(`#000000`) 외곽선 | 공식 외곽선은 네이비다. 검정은 경직된 인상을 만든다 |
| `#54B947` 맞물림 색 삭제 | **CI 계승의 유일한 증거다.** 이 색이 없으면 "CI와 무관한 새싹 그림"이 된다 |
| 흑백 반전(네거티브) | 흙더미·볼 투명도가 뭉쳐 판독 불가 |
| 투명도 임의 조정 | 볼 18%, 흙더미 30·35% 외 변경 금지 |

### 단색 1도 사용

인쇄비 절감·자수·각인용으로 **`#004B88` 1도**만 허용한다. 이때도 **품(빈 공간)은 반드시 비워** 종이·바탕색이 보이게 한다. 품이 메워진 단색 실루엣은 "안고 있는 자세"가 사라져 사용할 수 없다.

## 4. 조형 변형 — 허용과 금지

### 4-1. 허용 (별도 파일로 제작, §9 승인 후)

| 허용 | 조건 |
|---|---|
| 표정 변주 | 눈·입만 교체. **활짝 웃는 입·치아 노출 금지**(03 §4, 04 §5-1) |
| 자세 변주 | 머리:몸 비율, 떡잎 2장 비대칭, 두 팔 맞물림 구조는 **고정** |
| 선택 소품 추가 | 식은 보리차 컵, 접힌 담요 (03 §3-2 프로필 근거 품목만) |
| 상황 일러스트 | 교육·총회·명절 등. 품(빈 공간) 활용 가능 |
| 측면·후면 | 떡잎 비대칭이 유지되는 각도로만. 정면 조형이 마스터다 |

### 4-2. 금지 (예외 없음)

| # | 금지 | 사유 |
|---|---|---|
| 1 | **떡잎을 3장 이상으로** | CI의 "두 인물" 대응 구조 소멸 |
| 2 | **떡잎을 좌우 대칭으로** | "남 덮는 잎 / 나 덮는 잎" = 「돌보는 사람을 돌본다」의 조형적 전부 |
| 3 | **두 팔을 떼어 품을 열기** | CI 요람 곡선 소멸 |
| 4 | **맞물림 색 `#54B947` 제거** | CI 계승 증거 소멸 |
| 5 | **다리·발 추가** | 확정 조형은 다리가 없다(흙더미에 묻힘) |
| 6 | **CI 심볼에 얼굴을 붙이거나 늘리기** | 브리프 §3 금지 사항 직접 위반 |
| 7 | 가로세로 비율 왜곡·기울이기·회전 | 15° 이상 회전 시 떡잎이 머리로 읽힌다 |
| 8 | 그림자·입체 베벨·네온·글로우 효과 | 플랫 벡터 자산이다 |
| 9 | 윤곽선 제거 | 다크 배경·소형에서 소실 |
| 10 | 다른 캐릭터·연예인·실존 인물과 합성 | 권리 문제 + 중립성 훼손 |
| 11 | 정당·선거·정책 찬반 캠페인 사용 | 브리프 §3 + 02 §3-2 ⑦(해랑이 사례) |
| 12 | 민원인·국민을 부정적으로 묘사한 장면에 등장 | 03 §4-1 원칙 6 |
| 13 | 서류더미·과로·탈진 묘사 | 브리프 §3 금지 사항 |
| 14 | 음주·흡연·도박·의료행위 묘사 | 공공 자산 품위 |
| 15 | AI 생성 이미지로 품싹을 재현해 공식 사용 | 조형 규칙이 깨진다. 공식물은 반드시 원본 SVG 기반 |

> **②·③·④번은 재심의 사항이다.** 이 3개가 깨진 시안은 담당자 판단으로 수정할 수 없고, §9-2 절차로 되돌린다.

## 5. 언어 규칙 (보이스 & 톤 적용판)

### 5-2. 금지 어휘

- 정당·정파 연상 표현, 특정 정책 지지·반대 → **전면 금지.** 캐릭터는 성명 발표 주체가 될 수 없다
- "복지부동", "철밥통", "민원 끝판왕", "영혼 없는" → 금지
- "힐링", "소확행" 등 유행어 → 비권장(수명이 짧다)
- 사투리·유행 어미 → 금지(전국 17개 시·도 공용 자산)

| 탈인형 | 별도 3D 설계 | 신규 | 떡잎 2장·품 구조 유지 검수 필수 |

## 7. 17개 시·도 지회 확장 규칙

한사연은 **17개 시·도 지회**를 운영한다(브리프 §1). 지회가 각자 캐릭터를 변형하면 02 §3-2 실패 유형 B(전략 없는 반복 발주 → 정체성 희석. 전주시 캐릭터 11개·4.5억 원 사례)를 그대로 재현한다. 따라서 **지회 전용 캐릭터는 만들지 않는다.**

### 7-1. 허용되는 지회 표기 — 「명판 병기」 방식만

지회는 품싹 조형을 **건드리지 않고**, 캐릭터 옆 또는 아래에 **텍스트 명판**만 붙인다.

```
┌──────────────────────┐
│                      │
│      [ 품싹 ]         │   ← 조형 변경 없음. 공식 파일 그대로
│                      │
│   한사연 ○○○지회      │   ← 명판: 네이비 #004B88, 캐릭터 폭의 1.2배 이내
└──────────────────────┘
```

| 항목 | 규칙 |
|---|---|
| 명판 서식 | `한사연 ○○○지회` (기관 공식 지회명 그대로) |
| 글자 색 | `--ks-navy` `#004B88` 단색 |
| 위치 | 캐릭터 **하단 중앙** 또는 **우측**. 여백(§2-2) 바깥에 둔다 |
| 폭 | 캐릭터 폭의 **1.2배 이내** |
| 금지 | 지회명을 캐릭터 몸·수첩·떡잎 위에 쓰기 / 지회별 색 변경 / 지회별 소품 추가 |

### 7-2. 지회 자율 허용 범위

| 구분 | 지회 자율 | 사무처 승인 필요 |
|---|---|---|
| 공식 4종 파일 그대로 사용 | ○ | — |
| 명판 병기(§7-1) | ○ | — |
| 지회 행사 현수막·안내물에 사용 | ○ | — |
| 지회 자체 굿즈 소량 제작(100개 이하, 비판매·회원 배포용) | ○ (사후 보고) | — |
| 지회 전용 **표정·자세 변주** 제작 | ✕ | **필요** |
| 지회 전용 **소품 추가** | ✕ | **필요** |
| 판매용 굿즈 제작 | ✕ | **필요** (§8-4 수익 환원 규정 적용) |
| 외부 기관·업체와 공동 사용 | ✕ | **필요** |
| 지회 전용 **별도 캐릭터 신규 개발** | **✕ 전면 금지** | 불가 |

### 7-3. 지역 모티프를 넣고 싶을 때

지회 요청이 들어올 것을 전제로 미리 정한다: **지역 모티프는 캐릭터가 아니라 배경·소품 일러스트로 처리한다.**

- ○ 품싹(원본 그대로) + 배경에 지역 랜드마크 일러스트
- ○ 품싹의 품(빈 공간)에 지역 상징 아이콘 삽입 (별도 파일, §9 승인)
- ✕ 품싹에 지역 특산물 모자·의상 착용
- ✕ 지역 동물·식물로 떡잎 교체

### 8-2. 인쇄 발주 고지문 (그대로 복사해 사용)

> 본 캐릭터의 컬러 HEX 값은 한국사회복지행정연구회 공식 심볼의 디지털 샘플링 값입니다. **Pantone·CMYK 공식 지정값은 미확정**이며, 인쇄 발주 전 발주처와 색상 교정(Proof) 확인을 거칩니다. 특히 `#54B947`(두 팔 맞물림 지점)은 캐릭터의 CI 계승 요소이므로 **다른 그린과 구분되게 재현**되어야 합니다.

### 8-3. 공정별 치환 규칙

| 공정 | 치환 |
|---|---|
| 자수 | 그라데이션 → `#AED136` 단색. 잎맥·볼·동공 하이라이트 생략. 외곽선 네이비 유지 |
| 각인·레이저 | 단색 1도. 품(빈 공간)은 **관통 또는 미각인**으로 비운다 |
| 아크릴·키링 | 풀컬러 가능. 외곽 컷팅선은 흰색 보조 외곽선 바깥 1mm |
| 실크스크린(1~2도) | `#004B88` 1도 또는 `#004B88` + `#AED136` 2도 |
| 봉제 인형 | 떡잎 2장을 **별도 재단 피스**로 제작(프린트 금지). 좌우 길이차 1:0.5 유지 |
| AI/EPS 변환 | `mask` 손실 시 맞물림 색 소멸 → 변환 후 `#54B947` 구간 **육안 확인 필수** |

### 8-4. 굿즈 수익 처리 원칙

판매용 굿즈 수익은 **사회복지 기금 또는 회원 복지사업으로 환원**하고, 환원 내역을 연 1회 공개한다.

> **근거**: 용인시는 조아용 굿즈 매장을 지역자활센터 자활사업 참여자가 운영하게 하고 수익을 자립지원 기금으로 환원했다(02 §2-1 ⑥). 이 구조는 "왜 협회 예산으로 캐릭터를 만드나"라는 내부 비판에 대한 가장 강한 방어 논리이며, 한사연 정체성과 구조적으로 정합한다.

## 9. 권리·승인·관리

### 9-1. 권리 귀속과 개방 수준

| 항목 | 규정안 |
|---|---|
| 저작재산권 | **한국사회복지행정연구회에 전부 귀속.** 외주 제작 시 계약서에 **저작재산권 전부 양도 + 2차적저작물작성권 포함** 명시 |
| 상표권 | 「품싹」 문자상표 + 도형상표 출원. **KIPRIS 선행조사 후 진행**(03 §7-1) |
| 회원 사용 | **전면 개방.** 회원이 자기 업무자료·교육자료·발표자료에 자유롭게 사용 |
| 지회 사용 | §7 규칙 내 자유 |
| 외부 기관 | **사전 신청·승인제.** 공공기관 비영리 사용은 승인, 상업적 사용은 별도 협의 |
| 개방 유형 참고 | 용인 조아용은 공공누리 제4유형(출처표시·변경금지·비상업), 부산 부기는 저작재산권 전면 무료 개방(02 §2-1 ⑤). **한사연은 "회원 전면개방 + 외부 승인제"의 중간 모델을 권고** |
| 금지 | 회원·지회가 품싹을 **개인 또는 제3자 명의로 상표 출원**하는 행위 |

> **왜 회원에게 전면 개방인가**: 직능단체 캐릭터의 성공 지표는 외부 인지도가 아니라 **회원의 자발적 사용률**이다(02 §3-3). 사용 신청 절차를 회원에게 요구하면 아무도 쓰지 않고, 쓰지 못하는 캐릭터는 자산이 아니다.

### 9-2. 승인 절차

| 구분 | 절차 | 처리 기한(권고) |
|---|---|---|
| 공식 4종 파일 사용 | **승인 불필요** | — |
| 명판 병기 | 승인 불필요 | — |
| 표정·자세 변주, 소품 추가, 상황 일러스트 신규 제작 | 사무처 담당자 검토 → **§4-2 1~6번 대조** → 승인 | 7일 |
| §4-2 ②③④ 저촉 시안 | **담당자 수정 불가.** 캐릭터 관리 책임자 재심의 | 14일 |
| 외부 기관 사용 신청 | 사용목적·매체·기간 기재 신청 → 사무처 승인 | 14일 |
| 판매용 굿즈 | 사무처 승인 + §8-4 수익 환원 계획 첨부 | 30일 |

### 9-3. 자산 관리 — 자산이 사라지지 않게 하는 장치

02 §3-2의 실패 유형 중 **유형 D(공개·배포 인프라 부재)** 는 국가아동권리보장원 '아리', 근로복지공단 '희망'에서 실증되었다. 캐릭터가 있는데도 **공식 소개·다운로드 페이지가 없어 내부조차 쓰지 못하는** 상태다. 이를 막기 위해 아래를 필수로 한다.

| # | 조치 | 비고 |
|---|---|---|
| 1 | **홈페이지에 캐릭터 전용 페이지 개설** | 모티프 설명 + 프로필 + 금지 사례 + 다운로드 |
| 2 | **원본 파일 전면 공개**(SVG·PNG·AI) | 사회보장정보원은 기본형+응용형을 JPG·PNG·AI로 전면 공개, 공무원연금공단은 AI 파일 다운로드 제공(02 §3-3) |
| 3 | **요소별 가치 매핑표 게시** | 떡잎 2장=성장/감싸 안음, 맞물림 색=CI 계승, 왼쪽 떡잎=남을 덮음, 오른쪽 떡잎=자기를 감쌈, 수첩=기록. 공무원연금공단 믿음이 사례처럼 **홍보 설명자료가 자동 생산**된다 |
| 4 | 본 가이드라인 PDF 동시 게시 | 외부 업체가 바로 받아갈 수 있게 |
| 5 | **회칙·규정에 자산 귀속 명시** | 회장 교체 주기에 캐릭터가 폐기되지 않도록. 02 §2-1 ⑦ 고양고양이 약 4년 공백 사례 |
| 6 | 캐릭터 관리 책임자 1명 지정(사무처) | 담당자 변경 시 인수인계 문서 필수 |
