## 3. 핵심 조형 — 품(요람 곡선)

> **이 항목이 CI 계승 검증의 유일한 통과 조건이다. 어떤 파생물에서도 변형 금지.**

```
       ○            ← 머리 (x=50, y=44, r=21)
     ╭───╮
     │   │          ← 몸통 (y=59 → 88.5)
     ╰─┬─╯
    ╱     ╲         ← 두 팔 (발생 y=74)
   │  ( )  │        ← 품 : 빈 공간 (배경이 비쳐 보인다)
    ╲ ▓▓▓ ╱         ← 맞물림 지점 #54B947
      ▒▒▒           ← 흙더미
```

| 항목 | 확정값 |
|---|---|
| **팔 발생점** | 좌 `(34, 74)` / 우 `(66, 74)` |
| **팔 경로(왼팔)** | `M34,74 C26.5,84 26.5,98 33,105.5 C37.5,110.5 46,111.5 53,109.5` |
| **팔 경로(오른팔)** | `M66,74 C73.5,84 73.5,98 67,105.5 C62.5,110.5 54,111.5 47,109.5` |
| 팔 두께 | 심 7 / 네이비 외곽 11.4 / 흰색 보조 13.8 (모두 `stroke-linecap="round"`) |
| 팔 최대 벌어짐 | x=26.5 / x=73.5 (y≈91 지점) |
| **맞물림 구간** | **x 47 ~ 53, y 108 ~ 112.** 두 팔 경로가 교차하는 영역 |
| **맞물림 색** | **`#54B947`** — `mask`로 왼팔 형상을 추출해 오른팔 위에 덮어 구현 |
| **품(빈 공간) 치수** | 가로 약 28 × 세로 약 12 (x 36~64, y 91~103) |
| 품의 내용물 | **비워 둔다.** 배경색이 그대로 비친다. 어떤 색으로도 채우지 않는다 |

### 품을 "구멍"으로 구현하지 않은 이유 (중요)
초기 시안은 몸통에 마스크로 원형 구멍을 뚫어 품을 표현했으나, 렌더링 검증 결과 **흰 배경에서는 배에 붙은 흰 접시, 다크 배경에서는 복부의 상처**로 읽혔다. 확정본은 구멍을 뚫지 않는다. **몸통 하단과 두 팔 사이에 자연 발생하는 빈 공간**이 품이며, 따라서 어떤 배경색에서도 "안고 있는 자세"로 읽힌다.

> **확장 슬롯 운용**: 이 빈 공간은 상황 일러스트에서 다른 캐릭터·아이콘·짧은 메시지를 넣는 자리로 쓴다. 단 **기본형 파일에는 넣지 않는다.**

## 4. 떡잎 2장 (좌우 비대칭 — 임의 대칭화 금지)

| 항목 | 왼쪽 떡잎 (남을 덮는 잎) | 오른쪽 떡잎 (자기를 감싸는 잎) |
|---|---|---|
| 발생 위치 | 좌측 어깨선 `(32, 61)` | 우측 어깨선 `(65, 62)` |
| 방향 | 바깥으로 길게 올라가 머리 왼편을 덮는다 | 짧게 올라가 **자기 어깨 위에 접혀 내려앉는다** |
| 끝점(뭉툭) | `(18.5, 23.5)` | `(82, 52.5)` |
| 중심선 길이 | 약 43 | 약 21 (**왼쪽의 약 50%**) |
| 최대 폭 | 13 | 9 |
| 잎 끝 처리 | **뭉툭한 라운드.** 뾰족하게 깎지 않는다 | 동일 |
| 잎맥 | 중심맥 1줄 (`stroke-width 1.3`, 투명도 45%) | 중심맥 1줄 + **접힘 주름선 1줄** (`1.6`, 85%) |
| 색 | `#AED136` 단색 | `#AED136` 단색 |

**경로 원문**

```
왼쪽: M32,61 C22,54 13,43 11,30 C10,23.5 14,20.5 18.5,23.5 C23,30 28,42 33,52 C35,56 34,60 32,61 Z
오른쪽: M65,62 C70,56 77,51.5 82,52.5 C85,53 85,56.5 82,58.5 C78,61 72,63.5 68,66.5 C66,68 64,65 65,62 Z
```

| 금지 | 사유 |
|---|---|
| 떡잎 3장 이상 | CI의 "두 인물" 대응 구조가 깨진다 |
| 좌우 대칭화 | "남 덮는 잎 / 나 덮는 잎" 설정이 소멸한다. **이 비대칭이 「돌보는 사람을 돌본다」의 조형적 전부다** |
| 정수리 발생 | 식물 모자가 되어 팔로 읽히지 않는다 |
| 가지맥 추가 | 소형 사이즈에서 노이즈 |
| 잎 두께 6 미만 | 16px에서 소실 |

| 레이어 | 두께 | 색 | 목적 |

> 흰색 보조선은 **모든 조형 요소의 뒤에 한 겹으로 먼저 깔고**, 그 위에 색면을 올리는 순서로 구현했다. 요소마다 따로 흰 테두리를 두르면 겹침 구간에서 흰 선이 앞 요소를 가린다.
> **인쇄물 배경이 흰색일 때는 흰색 보조선을 제거해도 무방하다**(시각 차이 없음, 파일 경량화 목적).

## 7. 설계 변경 사항 (지시서 → 확정본)

> 지시서(`03` §5)와 다른 항목은 아래가 전부다. **변경 사유는 모두 렌더링 육안 검증에서 확인된 실제 문제**이며, 설계 의도를 바꾸지 않는 범위에서 조형만 조정했다.

| # | 지시서 | 확정본 | 변경 사유 |
|---|---|---|---|
| **1** | 머리:몸 = 1:1.15 | **1:1.25** | 요람 곡선(품) 확보를 위해 팔 구간이 아래로 연장되었다. 유아성 회피 기준(1:1 이상)은 충족하며, 머리 자체 크기는 지시서값(지름 42) 그대로다 |
| **2** | 품 = 두 팔 안쪽 **지름 20의 빈 공간** (몸통에 구멍) | **몸통 하단과 두 팔 사이의 빈 공간** (가로 28 × 세로 12) | 몸통을 뚫은 구멍은 흰 배경에서 "배에 붙은 접시", 다크 배경에서 "복부의 구멍"으로 오독됨. **구멍을 없애고 품을 몸 아래로 내려** 모든 배경에서 "안는 자세"로 읽히게 함 |
| **3** | 왼쪽 떡잎: 몸통 앞 `(50,92)`까지 크게 휘어 내려옴 | 머리 왼편을 덮는 **상향 차양 곡선**, 끝점 `(18.5,23.5)` | 몸통 앞까지 내려오면 품(요람 곡선)과 겹쳐 두 핵심 조형이 서로를 가린다. 또한 두꺼운 곡선을 급히 말면 **고리 모양으로 뭉쳐 "귀·달팽이"로 오독**(검증에서 확인). "덮는다"는 기능은 **품**이 전담하고, 떡잎은 길이 비대칭으로 설정을 전달한다 |
| **4** | 오른쪽 떡잎 = 왼쪽의 60% | 약 **50%** | 비대칭 판독력을 소형 사이즈까지 확보하기 위해 격차를 키움 |
| **5** | 짧은 팔 2개 + 떡잎 = 기능 분리 (팔 길이 22, 두께 7) | 팔 두께 7 유지, 길이 연장(요람 폐곡선 형성) | 길이 22로는 두 팔이 맞물리지 못해 **품이 닫히지 않는다.** 겹침색 `#54B947` 적용 지점 자체가 생기지 않으므로 CI 계승 검증을 통과할 수 없음 |
| **6** | 수첩 `x=74, y=84`, 14×18 | `x 69.5~83.5, y 73~87.5`, 14×14.5 | 원위치는 팔 경로와 충돌. 허리 높이로 올리고 팔 앞에 배치 |
| **7** | 볼 위치 `(30,46)` `(70,46)` | `(34.5,52)` `(65.5,52)` | 원위치는 머리 원 바깥. 머리 반지름 21 내부로 보정 |

**지시서에서 바뀌지 않은 핵심 4항목** (변경 시 재심의 필요)
1. 떡잎 정확히 2장 · 좌우 비대칭
2. 두 팔이 맞물려 품을 만드는 구조
3. 맞물림 지점 `#54B947`
4. 네이비 외곽선 · 활짝 웃지 않는 입

## 8. 인쇄·제작 주의

| 항목 | 내용 |
|---|---|
| **Pantone·CMYK** | **미확정.** 본 문서의 HEX는 공식 심볼 PNG 픽셀 샘플링으로 추출한 **디지털 기준값**이다. 조직이 공식 수치를 공개하지 않았으므로 **인쇄 발주 전 반드시 확인**한다 (브리프 §2) |
| 최소 인쇄 크기 | 기본형 **가로 15mm 이상**. 그 이하는 `poomsak-48` 조형을 쓴다 |
| 단색 인쇄 | `#004B88` 1도. 품(빈 공간)은 반드시 비워 종이색이 보이게 한다 |
| 자수·각인 | 그라데이션 불가 → `#AED136` 단색으로 치환, 잎맥·볼·동공 하이라이트 생략 |
| 벡터 원본 | SVG가 마스터다. AI/EPS 변환 시 **`mask` 요소가 손실되면 맞물림 색이 사라지므로**, 변환 후 `#54B947` 구간을 반드시 육안 확인한다 |
